# Лазерные принтеры Brother на Apple Silicon — нативный драйвер, без Rosetta

Лечит **«ПО принтера несовместимо с этим устройством»** для старых монохромных лазерных
Brother на macOS 27 / Apple Silicon.

Фирменный драйвер Brother (`rastertobrother*`, последняя сборка 2019 г.) собран только под
Intel. Если на Mac нет Rosetta 2 — или когда Apple её ограничит — macOS его отвергает.
AirPrint у большинства этих принтеров нет (они понимают только растр Brother HBP), так что
без драйвера не обойтись. Здесь лежит **[brlaser](https://github.com/pdewacht/brlaser)** —
открытый CUPS‑драйвер, десять лет работающий с этими принтерами в Linux, — **собранный под
arm64**, с PPD‑файлами и установщиком в одну команду.

> **Собрано из brlaser `master` (2a49e328, 2023‑02‑20), а не из релиза v6 — намеренно.**
> v6 режет растр на блоки по 64 строки, и движок HL‑1110/1210W/DCP‑1610W молча отбрасывает
> сложные страницы в такой кодировке (принтер щёлкает, ничего не выходит, CUPS считает
> задание выполненным — [issue #40](https://github.com/pdewacht/brlaser/issues/40),
> [PR #68](https://github.com/pdewacht/brlaser/pull/68)). В `master` полосы по 128 строк, как у
> фирменного драйвера, — печатается всё. Проверено на DCP‑1610W: v6 → 0 листов, master → печатает.

Если у вас МФУ (DCP/MFC) и нужна кнопка **«Открыть сканер…»** — см. [Сканер](#сканер-dcpmfc).

Если вашей модели нет — попробуйте ближайшую: по опыту brlaser, семейство почти целиком
работает с любым профилем «brlaser».

## Установка

Скачайте [последний релиз](https://github.com/alek511/brother-laser-apple-silicon/releases/latest) и распакуйте, или:

```sh
git clone https://github.com/alek511/brother-laser-apple-silicon.git
cd brother-laser-apple-silicon
sudo ./install.sh
```

Затем добавьте принтер **через Системные настройки** (не через `lpadmin`, см. ниже):

1. Системные настройки → Принтеры и сканеры → **Добавить принтер, сканер или факс…**
2. Выберите свой Brother в списке (сеть или USB).
3. Меню **Использовать** → **Выбрать ПО…** → в поиске `brlaser` → ваша модель → **Добавить**.

Готово. Напечатайте тестовую страницу.

Что установщик кладёт в систему:

- `/Library/Printers/brlaser/rastertobrlaser` — фильтр, arm64, ad‑hoc подпись (62 КБ)
- `/Library/Printers/PPDs/Contents/Resources/*.ppd` — по одному PPD на модель

Он же снимает флаг `com.apple.quarantine`, который macOS вешает на скачанное с GitHub —
иначе `cupsd` отказывается запускать фильтр.

## Сканер (DCP/MFC)

brlaser — только драйвер печати. Сканирование работает через фирменный ICA‑пакет Brother
(`Brother Scanner.app`): в отличие от драйвера принтера, он универсальный и работает
нативно. Если его нет — скачайте с сайта Brother.

Кнопка **«Открыть сканер…»** в карточке принтера появляется, только когда выполнены
*все три* условия:

1. в PPD есть `*APICADriver: True` (во всех PPD для DCP/MFC здесь он есть);
2. `*ModelName` в PPD совпадает с Bonjour‑именем сканера (например `Brother DCP-1610W series`);
3. очередь создана **через Системные настройки**, а не `lpadmin` — привязку делает само
   приложение Настроек в момент добавления.

В `ppd-tuned/` лежат PPD, уже подогнанные под пункт 2. Для другой модели скопируйте
стандартный PPD, впишите в `*ModelName` / `*ShortNickName` / `*Product` точное имя, которое
объявляет принтер (`dns-sd -B _scanner._tcp local` его покажет), и установите рядом.

Без кнопки сканер всё равно доступен из «Захвата изображений» и через «Импорт со сканера»
в любой программе.

## Если что‑то не так

Всё ниже встретилось при запуске DCP‑1610W на macOS 27. Формат: *симптом → причина → что делать*.

**«ПО принтера несовместимо с этим устройством».**
Драйвер Brother только под Intel, а Rosetta 2 на Mac нет. Либо ставьте этот драйвер, либо
`sudo softwareupdate --install-rosetta --agree-to-license`, чтобы остаться на фирменном.

**Принтер щёлкает один раз, ничего не выходит, CUPS пишет «выполнено».**
Классический отказ brlaser **v6** на движке 1110/1210W/1610W: простой текст печатается,
что‑нибудь плотнее — отбрасывается. У вас сборка из v6 — поставьте эту (из `master`, полосы
по 128 строк). Если повторяется — поймайте задание и откройте issue (шаблон есть).

**Задание висит в «Отправка» / «Подключение к принтеру» и не печатается.**
Сначала сам принтер: `nc -z <ip-принтера> 9100` должен проходить, а его веб‑страница (IP в
браузере) показывать Ready или Sleep, не ошибку. Один раз выключите‑включите его: серия
оборванных заданий (например, от Intel‑драйвера, падающего посреди отправки) может подвесить
движок.

**Нет кнопки «Открыть сканер…» у DCP/MFC.**
Три условия (см. [Сканер](#сканер-dcpmfc)): `*APICADriver: True` в PPD, `*ModelName`,
равный Bonjour‑имени сканера, и очередь, добавленная **через Системные настройки**. Замена
PPD через `lpadmin` кнопку не создаёт — удалите очередь и добавьте заново в Настройках.

**Драйвера нет в списке «Выбрать ПО…».**
`lpinfo -m | grep brlaser` должен показать 30 строк. Если пусто — на PPD остался флаг
карантина (установщик не отработал?) — повторите `sudo ./install.sh`.

**Предупреждение `lpadmin` «драйверы принтера не рекомендуются».**
Информационное. Apple объявила PPD‑драйверы устаревшими; на macOS 27 они работают. Фирменный
драйвер Brother получает то же предупреждение.

**Переключатель «Использовать универсальные функции принтера».**
Оставьте выключенным. Включённый — заставляет macOS игнорировать опции PPD.

**Не та / стандартная иконка.**
Так и задумано: иконки Brother — их графика, здесь их нет. Если пакет Brother установлен,
добавьте в свой PPD `*APPrinterIconPath: "/Library/Printers/Brother/Icons/<модель>.icns"`.

**1200 dpi ничего не печатает.**
Известно на части 1600‑й серии (brlaser #173). Используйте 600 dpi.

## Как нашли проблему v6

Стоит записать: симптом указывает куда угодно, кроме настоящей причины. Текст печатался; PDF
из Просмотра — нет, хотя CUPS рапортовал успех, а принтер принимал каждый байт на порт 9100.
Те же байты, отправленные на порт напрямую через `nc`, печатались — транспорт ни при чём.
Перехват задания локальной очередью `socket://127.0.0.1` показал: CUPS выдаёт ровно те байты,
что печатались напрямую. Отличалась *страница*: растр Просмотра плотнее, чем свежий рендер
того же файла. Перехват растра Просмотра (`cupsFilter … rastertopwg` в локальный сокет),
кодирование тремя сборками и отправка каждой с разным числом копий (1 / 2 / 4) дали
0 + 2 + 4 листа: v6 не работает, блоки по 32 строки работают, `master` работает.

## Удаление

`sudo ./uninstall.sh` — удаляет очереди печати, использующие brlaser, PPD и фильтр. Больше ничего не трогает.

## Пересборка из исходников

```sh
brew install cmake
./build.sh        # скачивает brlaser master (или ./build.sh 6 для тега), собирает, обновляет bin/ и ppd/
```

Работает и на Intel Mac (соберётся x86_64).

## Заметки

- Apple объявила PPD‑драйверы устаревшими (`lpadmin` пишет предупреждение). На macOS 27
  они работают. Долгосрочный запасной путь для таких принтеров — Raspberry Pi или любой
  Linux с CUPS + brlaser, раздающий принтер как AirPrint.
- Rosetta 2 на macOS 27 всё ещё ставится (`softwareupdate --install-rosetta`) и оживляет
  фирменный драйвер, но Apple обещала ограничить её в macOS 28. Этот драйвер от неё не зависит.
- Качество: 600 dpi — безопасное значение по умолчанию; 1200 dpi доступно, но не на всех
  моделях гарантировано.
- К Brother отношения не имеет. Иконки Brother не включены (это их графика); принтер
  получит стандартную иконку macOS.
